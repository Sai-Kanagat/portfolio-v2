Agency OS

I'm building the whole machine behind a one-person automation agency, from first lead to invoice to referral. Automation does the admin. A human owns every decision that matters.

The core idea

Workflows can't send anything

Most automation fails the same way: one workflow edit and it emails the wrong person. So the workflows here hold no send credentials. Every outbound action has to pass one tested service, which checks six things in a fixed order.

  1. Launch modeA single flag. A mistyped value counts as the safe setting.
  2. AllowlistBefore launch, only addresses I control can receive anything.
  3. Opt-outsOne click, honoured at once, for every kind of message.
  4. Country rulesBusiness addresses only, in markets switched on deliberately.
  5. Daily cap20 cold emails a day, at most.
  6. Human approvalNothing goes out without a click, apart from updates to existing clients.
What went wrong

Passing tests only prove what you thought to test

The first version passed every test and still had five problems, which I found by reading it as an attacker. The worst one let a cold email pose as a client update and skip approval. It's now fixed and has its own test.
