What this is

The brief → a finished campaign kit.

Marketing teams spend days turning a brief into research, copy, and creative. Cortex compresses that into one orchestrated run and hands back an editable, brand-checked kit: strategy, copy, a hero visual, a poster, a social carousel, a storyboard with a cut video, and a localized version — each asset scored for brand fit by a vision model that can send it back to be regenerated.

01

Upload your brand

Drop in a brand book (PDF or image). A multimodal agent extracts the palette, voice, and do/don'ts, so everything downstream stays on-brand.

02

Name the occasion

"New Year campaign for our EV scooter." Agents research the market, the moment, and the audience before a single word is written.

03

It makes the media

Copy, hero, poster, carousel, a storyboard and a stitched video — real generated assets, not prompts.

04

It checks itself

A vision agent looks at every image, scores brand-fit and quality, and regenerates what fails. Then you approve, edit, or reject.

Architecture

A real multi-agent pipeline.

Ten specialist agents on a LangGraph state machine, each resilient (one failure degrades the run, never crashes it). Every model call is routed by cost tier, metered, and traced. A human gate can pause the whole graph and resume it.

Guardrails + security

Prompt-injection neutralization, PII redaction, output moderation, publish-gating, rate limits. An adversarial red-team test suite proves it.

Memory + RAG

Short-term checkpointer, long-term brand vectors, episodic run history. Research is grounded in the uploaded brand, with citations.

Observability + cost

Per-agent tracing (latency, tokens, USD), model-tier routing, prompt caching. You see exactly what each step cost.

Eval + tests

Golden-set evals, an LLM judge, and 52 automated tests including concurrency, fuzz, and the visual-QA regenerate loop.
